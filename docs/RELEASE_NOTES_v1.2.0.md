## v1.2.0 — 超额角标显示超出分钟数

### 变更
- **超额后角标改为显示超出分钟数**：达到每日额度后，工具栏角标由红色"今日已用分钟数"改为红色"超出额度的分钟数"
  （如额度 120 分钟、用掉 121 分钟时显示 `1` 而非 `121`），与系统通知"超过限制额度 X 分钟"的口径一致
- 刚好用完额度时显示红色 `0`（超出 0 分钟）；超额超过 999 分钟仍显示 `999+` 封顶
- 未达额度时蓝色剩余分钟数的行为不变
- 角标行为描述同步更新：`README.md`、`README_zh.md`、`docs/IMPLEMENTATION.md`、
  商店英文长描述 `store/LISTING.en.md`
- `manifest.json` 版本升到 1.2.0；`store/LISTING.md` 备注同步

### 兼容性与隐私
- **未新增任何权限**：仍为 `storage` / `tabs` / `alarms` / `notifications` / `idle`
- 无新增网络请求，仍为完全本地运行

### 测试说明
- VM 上 Node 测试桩 8/8 通过（`js/notify.js` 角标逻辑）：
  未超额（蓝，剩余分钟）/ 刚好达额（红 `0`）/ 超 1 秒（红 `1`）/
  121/120（红 `1`）/ 208/120（红 `88`）/ 超大超额（红 `999+` 封顶）/ 同日不重复通知
- 静态校验通过：`node --check js/notify.js`、`node --check background.js`
- locale 校验通过：`node scripts/check-locales.mjs`（en=29，zh_CN=29，0 错误 0 警告）
- **未在真实浏览器中加载验证**（VM 无桌面 Chrome），发布前请用「加载已解压的扩展程序」实测一遍
